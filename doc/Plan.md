# 近期计划

## 1. 跑通最小 Harness

明确模型能获得什么信息、维护什么记忆、执行哪些操作，确认教师能在一批明确选定的任务上稳定运行并完成导航。保存完整交互轨迹，供后续训练和失败分析使用。

## 2. 尽早建立小规模轨迹 SFT 基线

使用教师的完整导航轨迹训练一版小模型，无需等待全部空间任务设计完成。在同一 Harness 下评估，确定仅训练完整轨迹能解决多少问题，以及仍有哪些稳定出现的缺陷。

## 3. 针对剩余缺陷补充空间操作训练

优先选择一两类明确的能力缺口，例如空间记忆使用、地图与当前视野对齐或行动修正，构造针对性训练任务。与继续增加完整轨迹训练的方案比较，尽量对齐训练预算；确认收益后再扩大任务集合，最终完成完整对照与消融。

先以工作假设推进，不预先断言模型“只会模仿”。轨迹 SFT 基线应在前期出现，用于校准方向，再决定是否大规模构造空间任务数据。
