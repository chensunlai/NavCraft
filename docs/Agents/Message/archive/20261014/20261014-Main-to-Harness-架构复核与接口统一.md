# 架构复核与设计边界

- 发送方：Main
- 接收方：Harness
- 日期：2026-10-14
- 状态：目标设计已归档。

总体保留单 Agent、文件空间记忆、九工具和预算触发压缩。各任务使用一致的空间表示与工具语义，并明确以下设计边界：

1. QA 以最终回答提交结束；局部 IA 达成事件后立即终止剩余动作；完整导航保持显式 `nav_finish`。终止与私有评分分开。
2. 每条任务声明初始资料、可读资源和工具范围，读写、搜索、绘图及 Python 使用同一公开范围，不能绕过 A01 等任务的信息限制。
3. 记忆旧版本用于审计和训练回放；模型重新查证使用公开图片和动作记录，不开放完整私有 trace，也不增设版本查询工具。
4. 连续目标切换时保留环境记忆，更新当前目标与计划；定位估计绑定观察时刻，地图显示读取该记录，不维护第二套位置状态。
5. 回看旧图保留原采集时刻，只有实际采集才产生新观察；纠错时修正仍在使用的旧对应及受其影响的定位与计划。现有工具即可支持，无需新增记忆机制。

完整设计见 [Architecture](../../../../Architecture.md#harness)、[SpatialMemory](../../../../SpatialMemory.md) 和 [Tasks](../../../../Tasks.md)。后续反馈聚焦这些表示和工具能否支持对应、定位、查证、短期规划与执行，不预设固定导航阶段。
