## 本轮明确的设计

模型使用标准增量会话，自主查询、观察、计算、编辑记忆与运动。正式记忆通过统一文件编辑接口更新；地图显示读取图元和定位状态，不另存一套箭头状态。Python 读取公开资料和记忆，写入 scratch；实际观察与运动统一经过导航工具。

三种空间记忆指平面图、文本、证据图片；场景资料、执行记录、模型判断只是来源和可写性区分。新观察不自动关联真值房间或物体。初始定位提示之后仍由模型自行维护估计。

上下文平时增量追加，到输入预算或服务图片上限时统一摘要旧历史并移出旧图，不按固定轮次删图，不每轮重组整个工作空间。所有工具输入、返回、实际模型上下文及文件版本需要可追溯，供后续局部任务和完整轨迹训练使用。

## 设计边界与后续反馈

本阶段使用预构建只读基础地图；模型可维护定位估计、实体补充和自由笔记，在线几何构图留待后续扩展。请以两份正文为依据，反馈工具、记忆或任务信息条件是否足以支持自主空间判断与行动。
