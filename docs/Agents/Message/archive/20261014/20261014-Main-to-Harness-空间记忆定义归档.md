## 本轮归档范围

统一说明平面图的区域、墙体、出入口、主要物体、跨层连接和未知部分；明确实体文本、关系描述及 RGB 证据的内容。三者通过实体 ID 与图片引用关联，运行中的位置估计、对应假设和局部计划单独叠加。

已有资料之间的关联不等于当前观察已被正确定位：模型仍需建立新观察与实体的对应。区域边界不等于墙，开口不保证可通行，示意 box 不等于精确占据范围；关系应说明参考系，动态判断应说明时刻和依据。

## 设计边界与后续反馈

本阶段基础地图、实体卡和归档证据只读；模型通过统一编辑工具维护位置估计、实体补充和自由笔记。定位绑定观察时刻，判断注明依据。每个实体只保存当前补充，历史版本用于审计和训练回放，不引入手工修订链或运行期语义反向索引。

在线修改地图几何留待后续扩展。Python 用于公开资料上的计算与可视化，产物写入 scratch；正式记忆统一经编辑工具更新。后续 Harness 与任务设计请使用这份定义，并反馈空间对应、查证与行动之间是否存在信息缺口。
