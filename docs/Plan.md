# 近期计划

## 1. 跑通最小 Harness

明确模型能获得什么信息、维护什么记忆、执行哪些操作，确认教师能在一批明确选定的任务上稳定运行并完成导航。保存完整交互轨迹，供后续训练和失败分析使用。

## 2. 尽早建立小规模轨迹 SFT 基线

使用教师的完整导航轨迹训练一版小模型，无需等待全部空间任务设计完成。在同一 Harness 下评估，确定仅训练完整轨迹能解决多少问题，以及仍有哪些稳定出现的缺陷。

## 3. 补充空间操作训练，验证是否优于直接训练轨迹

优先选择一两类明确的能力缺口，例如空间记忆使用、地图与当前视野对齐或行动修正，构造针对性训练任务。

**核心验证：加入针对性空间操作训练，是否比仅直接训练完整导航轨迹更好。** 从同一轨迹 SFT 检查点出发，对比继续训练完整轨迹与加入空间操作训练两种方案，尽量对齐后续训练预算，保持 Harness 和评估条件一致。在未见场景的完整导航任务上比较成功率、路径效率和错误恢复表现，不能仅凭原子任务分数提高判断有效。确认收益后再扩大任务集合，最终完成完整对照与消融。

先以工作假设推进，不预先断言模型“只会模仿”。轨迹 SFT 基线应在前期出现，用于校准方向，再决定是否大规模构造空间任务数据。
