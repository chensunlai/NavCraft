NAVIGATION-GROUNDED SPATIAL TASKS

从空间判断，
到真正的导航行动。

看清楚每一道题给模型什么、要求它做什么，以及怎样判断做对了。相近题型按能力放在一起，真实样例与后续设计分别标明。

先看形式，再看能力

每道题从一个保存下来的状态开始。“切点”就是当时的观察、位姿、记忆和已有交互；它不是一条新的提示词。

QA · 查证后回答

可以查看已有图片、地图和记忆。不得移动、拍摄新图或改正式记忆，答案绑定切点时刻。

Agent 决策 · 短窗口内做对

检查真实调用和窗口结束的记忆。维护题通常直接接着上一条工具回执运行，不提醒模型“现在写记忆”。

Agent 执行 · 实际完成事件

需要真实行动并提交，按到达、穿门等实际事件评分。文字说“到了”不能代替执行。

当前8类试验任务默认使用 super 工具。QA 可以进行工具辅助的查证，因此不能把其成绩解释为纯视觉能力。检查者可展开私有标准答案；这些内容不会提供给被测模型。
