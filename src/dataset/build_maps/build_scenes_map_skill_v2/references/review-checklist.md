# 多轮复查：检查什么、如何裁决

## 第一轮：结构与事实

| 问题 | 必须查看的证据 | 修改与停止误判的依据 |
|---|---|---|
| 灰区／未命名空间 | 邻接房间面向该区、沿边界搜索、可达内部反向视图，地面与高度 | 标签缺失、截图里没看见不等于没有房间。发现走廊／入口便新增分区；充分取证仍缺失时，wall 按补全规则选定边界并保留来源；wall_real 保留证据缺口 |
| 孤立房间 | 四周边界、每个候选门的两侧、同层路径 | 先排查错门、漏门、重复墙、房间 ID 错配。真实闭门或扫描断连保留原因，不强制开口 |
| 门位置与连接对象 | 门框、门扇、门楣、实际开口及两侧室内景物 | 不能把向旁边打开的门扇当门洞；不能只按到区域边界的距离猜连接对象 |
| 画了绿门但仍不通 | 所有重合／平行墙线与开口跨度，局部路由穿越 | 开口必须实际切断该处全部阻挡墙线；绿线覆盖黑墙不算打开。两侧区域应对齐同一开口 |
| 闭门／镜子／玻璃 | 不同视角、深度，必要时碰撞或穿越反馈 | 镜中空间不建成第二房间，玻璃不当空气，关闭外门不声称可到达门外 |
| 多层与楼梯 | 楼层高度、踏步、平台、上下端图和对应高度路径 | 不用另一层 NavMesh 删本层墙。楼梯上下行方向、连接楼层、平台均要对应；同一平面位置不等于同一楼层 |
| 挑空／围栏／场景外围 | 上下层视图、栏杆与柱体、多高度墙面与斜顶、楼板范围 | 无楼板不等于无墙；护栏纳入 wall，场景边界与实体墙在数据中区分，不填成可行走楼面 |
| 破损补墙 | 原网格局部、多个高度支撑、相关 RGB、穿越路径 | 支持墙走向与支持开口存在分别判断。大补全标依据；若封已核实门或挡路径，回退并重新检查 |

路径核验优先选开口两侧的近点，先确认点在正确房间和楼层；NavMesh snap 的位移必须记录和检查。最短路应穿过目标开口，不能绕远处另一扇门后声称本门可通。检查路径与示意墙是否相交。NavMesh 通路只证明模拟器的对应通行关系，不能恢复真实门宽或未知墙厚。

## 第二轮：整图几何与物体

1. **坐标与尺度**：轴方向、层高、图层范围、相机位置一致。对照两个以上相距较远的锚点排除整体平移／镜像；多层面板使用可比较比例尺。
2. **墙线接缝**：共享墙错位、重复线、假缝、拐角不闭合或把开放区封闭。不同房间独立绘制再拼接经常产生双墙封门，应以同一结构边界对齐。
3. **分区**：同层房间不无故重叠；走廊不要漏进灰区；楼梯单独分区；功能区边界不自动实体化。未知占位不能暗示已测得其外围墙。
4. **家具越界**：逐个检查 box 是否在所属房间内、是否穿墙、占用门洞／楼梯、位于错误楼层或房间。先判断是墙错、分区错、物体位置错，不能直接缩盒。
5. **独立家具重叠**：特别看 L 形沙发与背后窄桌、沙发和窗边凹角、餐桌与餐椅、床头柜、柜门附近。根据 RGB 和主体几何简化；允许将示意椅子小幅展开，不能靠巨量位移掩盖错位。
6. **复合物体**：L 形的几个 box 必须属于同一物体并相接，不能把扫描噪声或完整 AABB 填成实心大矩形。
7. **合理投影嵌套**：盆体嵌入台面、柜上摆物等可保留并记录 `supported_by`；独立家具不能用这个字段免检。高度导致的真实投影重叠要显示层次或简化表达，不必机械清零所有二维交集。
8. **类别与朝向**：书柜可能是装饰搁架，桌面可能属于柜台；镜中重复实例、语义误标要回看 RGB。不要机械使用原始标签。斜放家具可用旋转 box，不强制全部正交。
9. **证据质量**：每个物体至少一张可辨视图，主体不能被近墙、背面或其他物体完全挡住。语义像素筛选只找候选，关键图仍需实际看。新增／改名／改房间的物体同步证据。
10. **显示质量**：房名和家具标签不遮门；房间图、纯墙图、纯物体图分别浏览。放大疑点后再看整层，防止局部改好而破坏整体。

## 第三轮：修改后回归与交付

- 对改动墙段两侧及相邻房间重新检查，重跑开口与物体关系。版本变化后旧的 passed 失效。
- 汇总每个已建模区域的连接。孤立组件必须有经核验的原因；跨层边不能靠二维相交推导。
- 检查主图、中文描述、JSON、门状态、房间 ID 和证据帧讲的是同一个最终版本；已采用估计可以在最终 wall 画实线，但正文与数据必须说明补全来源；wall_real 不混入这些估计。
- 对归档运行脚本，检查五项顶层、相对链接、帧存在、实例归属、独立图层及校验和。确认打开的是新主图而非旧缓存。
- 已确认的伪墙／错门、未知原因孤立房间、无解释穿插／越墙未解决时，不标记 reviewed。允许证据层仍有不可见空间，但最终 wall 须完成边界裁决；写清实测支持与采用估计，不能用未决标记代替补全。

复查结果按错误类型汇总，不能只写“图更规整”。若两轮额外取证没有新增有效信息，停止重复采集。墙体补全模式按 [墙体规则](wall-completion.md) 采用合理方案并记录来源；仅观测模式及非墙体信息才保留未决状态。继续修正明确错误，逐场景任务不得在当前场景未验收时自行切换。
