# 墙体补全与楼梯交付

在构建或复查墙体阶段阅读。重复的图层绘制、门洞裁切、阶段校验与校验和计算使用 [墙体工具](wall-tools.md)。默认使用用户已确定的阻挡边界口径；用户明确只要观测几何时，则保留缺口并说明，不强制补全。

## wall 与 wall_real

- **wall** 是最终可用的阻挡示意图：包括实体墙、围栏／护栏、场景外围边界，以及大范围扫描缺损处选定的补全边界。墙不以满高、不透明为必要条件。功能区划线、家具轮廓、活动门扇不是永久墙。
- **wall_real** 是补全前、由原网格和实际 RGB 支持的示意墙体及护栏；不是原始网格本身，也不是精确测绘真值。先保存此层，再添加估计段，不能把以前已估计的墙混入“真实”层。
- 最终 wall 统一用实线，不能仅去掉问号或把虚线变实线：每一处缺口都要有具体的保留开口／接缝连接／补墙／场景边界裁决。不能留下 Uxx 问号、待定墙段或未决几何后宣称本场景墙体已完成。
- 补全采用合理的单一几何方案，并在数据记录 `origin: inferred_completion`、依据、估计尺寸与覆盖的原缺损位置；选定方案不等于实测确定。扫描未恢复的事实保留在 wall_real 与复查记录，不要求在最终主图继续显示问号。

每段保留 `id, level, start, end, kind, origin, status, basis, evidence_frames`。建议 `kind` 为 `wall`、`railing`、`scene_boundary`、`missing_scan_boundary`；`origin` 为 `observed_schematic` 或 `inferred_completion`。`status: resolved` 表示已选定交付几何，不表示该段已实测。护栏沿楼梯变化的高度、二层外围借用下层投影等情况另记高度解释。

## 补全裁决

1. 从最新归档读取源数据，保留旧版图与相关 JSON。先查已存在的估计标记，抽出有证据的 wall_real。
2. 对每处缺损检查相邻墙端、上方墙面、天花、门洞和多个高度切片，再看实际渲染。不能用镜像、透视穿帮或黑洞片段凭空增加房间。
3. 采用有支撑的延伸、邻接外墙共线或合理的示意深度形成确定边界。闭门后的范围允许估计，但不能把深度说成测量值，也不能因此宣称门可通行。不要套用某个示例场景的深度或坐标。
4. 大范围缺失作为边界阻挡处理，不放任缺口暗示可继续通行；已核实的真实开口保留。补墙若跨越实际通道，回到证据检查位置、楼层和路径高度；若 NavMesh 自身通过扫描洞漏到场景外，明确记录该路径不作为真实开口证据。
5. 挑空必须分清外围高墙、斜顶、围栏、墙柱和无楼板区域。“无二层楼板”不能作为漏画墙／护栏的理由。最终 wall 可用场景边界封闭建筑外围，仍保留挑空标识，不把挑空填成可行走楼面。
6. 护栏与柱体或侧墙重合时，只保留一份阻挡线；短栏杆与楼梯斜护栏也要检查。不要把上平台出入口横向封死。

## 楼梯

墙体阶段也必须交付楼梯，不等待房间分区阶段。单独保存楼梯 ID、连接楼层、高度、平面范围、上下端、转角平台、上行折线、踏步线与证据。

- 从实际踏步高度确定上行方向，不能凭“图上左边／右边”猜。分别查看下端向上、上端向下及平台出口。
- 在关联楼层中绘制范围、踏步和带箭头的方向线，明确 `UP TO L2` / `DOWN TO L1` 等目标层。转角应随真实走向绘制，不能只在空白处放一段文字。
- 同一楼梯投影在两层出现不等于该范围都是平地；一层楼梯下空间的门不能画成上层楼梯出口。区分坡段护栏投影与楼层平面上的满高墙。
- 查询楼梯上下端的跨层 NavMesh 路径，检查 snap 位移、所在高度、经过的楼梯范围、上行方向及与墙的交叉。路径仅给出稀疏折点时，沿线段插值采样后判断中间高度与方向，不能要求每个踏步都有路径节点。无 NavMesh 时使用可用几何／移动验证并写明未运行的检查。

## 交付与验收

在 `raw/` 保存最终 `walls.json`、`wall_real.json`，各自的 PNG/SVG、施工源线和渲染后实际线段，以及 `stairs.json`。`scene.json.files.wall` 可指向 `walls.json`；若额外提供 `wall.json` 兼容别名，内容必须一致，不让两个文件独立漂移。`floor_plan.png` 使用最终 wall。

验收至少包括：

- 实际打开修改后的两套图、整层图和关键局部；确认围栏、外围、缺失区、楼梯都没有漏项。
- 检查重复墙段、接缝、门洞是否真正切开所有重合墙、保留开口和自由端的原因。自由端可能是壁柱返边或楼梯入口，不为机械闭合而堵通道。
- 核对 wall_real 无补全段，两套线段与证据一致；最终 wall 不含未决几何。必要的证据层缺口不得误报为最终 wall 的缺口。
- 重跑修改后的门口局部、同层路径和跨层楼梯检查；记录输入散列，数据变化后不得沿用旧检查。实际未做的动作验证不写“已走通”。
- 同步图、JSON、中文说明、复查记录、版本和校验和。复查记录区分“证据仍缺失，但已采用补全方案”和“几何尚未决定”；前者可交付完整示意图，后者不能标记完成。

用户要求逐个场景时，当前场景完成上述验收后才进入下一场景。发现漏墙或用户指出错误，重新打开当前场景处理；不能因为已经生成 PNG、跑完固定轮数或写了 partial 就自动切换。需要外部信息且确实无法继续时报告具体阻塞，不伪造通过，也不自行跳过。
